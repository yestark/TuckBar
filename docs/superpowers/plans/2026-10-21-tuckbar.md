# TuckBar Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build and publish a native macOS menu bar utility that groups icons into a collapsible region.

**Architecture:** AppKit owns two NSStatusItems: a divider and a persistent toggle. A pure Swift state model calculates divider width from connected displays. Users arrange third-party icons using macOS Command-drag.

**Tech Stack:** Swift 6, AppKit, Swift Package Manager; macOS 13+; no dependencies.

**Spec:** The user's request: hide selected menu bar apps, rearrange icons, reveal with one button, name the app and publish to the user's GitHub as open source.

## Global Constraints

- App name: TuckBar / 藏栏. MIT license.
- No private APIs, accessibility access or screen recording.
- Start expanded; user explicitly chooses when to collapse.
- Physical menu bar expansion cannot guarantee all icons fit beside a notch.
- Public repository: yestark/TuckBar, subject to name availability.

## Review Focus

- Multi-display changes: recalculate divider length using the widest display.
- Oversized displays: cap status item length at 10,000 points.
- Invalid divider order: do not collapse if the toggle could be hidden.
- User quits: restore normal divider width before removing items.
- Relaunch / wake: preserve saved positions, start expanded.
